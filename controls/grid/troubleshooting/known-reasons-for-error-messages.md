# Known Reasons for RadGrid Error Messages

This article lists common causes and solutions for errors raised by **RadGrid** for ASP.NET AJAX.

## "Cannot Find Any Bindable Properties"

This error usually occurs when the grid's **DataSource** is `null`, is not assigned, or the **NeedDataSource** event is not handled correctly. In a hierarchical grid, the error can also occur when a detail table has no data source or the **DetailTableDataBind** event is not handled correctly.

When you need to assign an empty source to a master or detail table, use an empty object array instead of `null`.

> caption Assign empty data sources to the master and detail tables

````C#
RadGrid1.MasterTableView.DataSource = new object[0];
RadGrid1.MasterTableView.DetailTables[0].DataSource = new object[0];
````
````VB
RadGrid1.MasterTableView.DataSource = New Object() {}
RadGrid1.MasterTableView.DetailTables(0).DataSource = New Object() {}
````

## "Unexpected AJAX Response Was Received from the Server"

This error can be caused by any of the following conditions:

- Calling `Server.Transfer` during an AJAX request
- Loading an AJAX-enabled user control incorrectly
- Using a custom HTTP handler that changes the response

For related guidance, see [Dynamically loading RadGrid as a user control]({%slug grid/create-radgrid/loading-user-control-with-telerik-radgrid-at-runtime%}) and [Dynamically loading user controls with AJAX controls]({%slug ajaxmanager/how-to/load-user-controls%}).

## Inserted-Item Binding Errors

The following errors can occur when a newly inserted item cannot receive a value through a hard-coded `Eval()` or `Bind()` expression:

- `Telerik.Web.UI.GridInsertionObject does not contain a property with the name <some_name>`
- `DropDownList has a SelectedValue which is invalid because it does not exist in the list of items`

Use one of the following approaches to resolve the error:

- Set default values in the `ItemCommand` handler when the `RadGrid.InitInsertCommandName` command is raised. For an autogenerated edit form, pass the values to `InsertItem`.
- Do not set the control value declaratively with an `Eval()` or `Bind()` expression in the page or user control markup.

> caption Set predefined values before inserting a new item

````C#
protected void RadGrid1_ItemCommand(object source, Telerik.Web.UI.GridCommandEventArgs e)
{
    if (e.CommandName == RadGrid.InitInsertCommandName)
    {
        e.Canceled = true;

        System.Collections.Specialized.ListDictionary newValues = new System.Collections.Specialized.ListDictionary();
        newValues["<ColumnDataField>"] = "<predefined_value>";

        e.Item.OwnerTableView.InsertItem(newValues);
    }
}
````
````VB
Protected Sub RadGrid1_ItemCommand(source As Object, e As Telerik.Web.UI.GridCommandEventArgs) Handles RadGrid1.ItemCommand
    If e.CommandName = RadGrid.InitInsertCommandName Then
        e.Canceled = True

        Dim newValues As New System.Collections.Specialized.ListDictionary()
        newValues("<ColumnDataField>") = "<predefined_value>"

        e.Item.OwnerTableView.InsertItem(newValues)
    End If
End Sub
````

For more information about predefined values for autogenerated column editors, see [Inserting values using InPlace and EditForms modes]({%slug grid/data-editing/insert-records/inserting-values-using-inplace-and-editforms-modes%}). For custom edit forms that use a **WebUserControl** or **FormTemplate**, see [Inserting values using a user control or FormTemplate]({%slug grid/data-editing/insert-records/inserting-values-using-usercontrol-formtemplate%}).

## "These Columns Do Not Currently Have Unique Values"

This error can occur for the following reasons:

- Values in the data source differ only by whitespace. For example, `heath j aldrich` and `heath j aldrich ` can be treated as different values during grouping. Normalize the values so that equivalent values use the same whitespace.
- Cells in a grid column have the same text but different captions. Set **RadGridInstance.GroupingSettings.CaseSensitive** to `false` when the grouping scenario does not require case-sensitive comparisons.
- The grouping expressions use **FieldAliases**. Removing the **FieldAlias** can prevent the exception, but grouping results can differ when items have equal text and different captions.

## Sorting Errors with IEnumerable Data

The following error appears when an `ObjectDataSource` returns a generic collection that does not support automatic sorting:

`The data source '<dataSourceName>' does not support sorting with IEnumerable data. Automatic sorting is only supported with DataView, DataTable, and DataSet.`

Implement sorting in the object data source, or bind the collection in the [NeedDataSource event]({%slug grid/server-side-programming/events/needdatasource%}) so that RadGrid can perform its native sorting. You can also set **OverrideDataSourceControlSorting** to `true` on the **MasterTableView** or **GridTableView**. The default value is `false`.

## Internet Explorer Export Error from an SSL Page

When exporting from an SSL page in Internet Explorer, you can receive the following error:

`Internet Explorer cannot download 'file' from 'server'. Internet Explorer was not able to open this Internet site.`

Clear the response headers and set the response cacheability to private immediately before exporting:

- `RadGrid1.Page.Response.ClearHeaders();`
- `RadGrid1.Page.Response.Cache.SetCacheability(HttpCacheability.Private);`

## "An Asynchronous Operation Cannot Be Started at This Time"

For the cause and solution, see [Errors when Page Async is true for the async-await pattern]({%slug common-errors-when-page-async-is-true-for-the-async-await-pattern%}). The page must be marked with `Async="true"`, and asynchronous methods should return `Task` instead of using `async void`.

The full error message is:

> An asynchronous operation cannot be started at this time. Asynchronous operations may only be started within an asynchronous handler or module or during certain events in the Page lifecycle. If this exception occurred while executing a Page, ensure that the Page is marked `<%@ Page Async="true" %>`. This exception may also indicate an attempt to call an `async void` method, which is generally unsupported within ASP.NET request processing. Instead, the asynchronous method should return a `Task`, and the caller should await it.
